# Recursos de Google Play Games

Recursos preparados para **Configuración > Editar propiedades** del proyecto de
Servicios de Juegos de Google Play.

## Propiedades recomendadas

- Idioma predeterminado: Español (Latinoamérica) (`es-419`)
- Nombre para mostrar: `Traidores`
- Categoría: Estrategia
- IDs de nueva generación: Activado
- Recall: desactivado por ahora
- Juegos guardados: Activado

Descripción:

> Traidores es un juego de deducción social donde cada jugador recibe un rol
> secreto. Investigá, mentí, debatí y votá para cumplir el objetivo de tu bando
> antes de que el pueblo caiga en manos de los traidores.

## Archivos

- `game_icon_512.png`: icono del juego, PNG de 32 bits, 512 × 512.
- `feature_graphic_1024x500.jpg`: gráfico de funciones, JPG de 24 bits,
  1024 × 500.

El gráfico de funciones usa el fondo del menú y el emblema de Traidores como
referencias visuales para conservar la identidad del juego.
