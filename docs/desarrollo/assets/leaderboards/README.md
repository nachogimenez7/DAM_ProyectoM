# Íconos de marcadores de Google Play Games

Archivos finales:

| Marcador | Nombre predeterminado (`en-US`) | Traducción (`es-419`) | Ícono |
|---|---|---|---|
| Victorias totales | `Total wins` | `Victorias totales` | `leaderboard_total_wins.png` |
| Partidas jugadas | `Matches played` | `Partidas jugadas` | `leaderboard_total_matches.png` |

Los dos archivos están exportados como PNG de 512×512, 32 bits y menos de 1 MB.

## Configuración compartida

- Formato: número.
- Decimales: 0.
- Unidades personalizadas: desactivadas.
- Orden: más altas primero.
- Protección contra manipulaciones: activada.
- Límites mínimo y máximo: sin definir.
- Orden de lista: victorias 1; partidas 2.

## Dirección visual

Se generaron usando la colección de medallones de logros como referencia de estilo:
ilustración pintada con volumen 3D controlado, metal envejecido, composición circular frontal,
fondo oscuro, luz cálida y la pequeña marca `T` en el aro inferior.

- Victorias: corona central con laureles sobre esmalte rojo oscuro.
- Partidas: libro de registro con marcas de conteo y dos fichas de jugador.
