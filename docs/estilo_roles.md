# Estilo de ilustraciones de roles

Este documento guarda la direccion visual aprobada para no perder consistencia al generar el resto de roles.

## Estilo base aprobado

- Ilustracion fantasy estilizada.
- Simple, limpia y legible.
- Caricaturesca, pero no infantil.
- Menos textura y menos detalle que una carta realista.
- Fondo del mapa suavizado, atmosferico y sin competir con el personaje.
- Personaje centrado en composicion vertical.
- Sin texto, sin logo y sin marco de carta.
- Cada rol debe diferenciarse por paleta, silueta y accesorios principales.

## Referencias aprobadas

- Asesino medieval: `app/src/main/res/drawable/rol_asesino_medieval_prueba_4.png`
- Detective medieval: `app/src/main/res/drawable/rol_detective_medieval_prueba_2.png`
- Aldeana medieval: `app/src/main/res/drawable/rol_aldeano_medieval_prueba.png`

## Prompt base

```text
A clean stylized fantasy character illustration of a [ROLE] for a social deduction card game. Simple readable caricature-like style, polished mobile game character art, smooth clean surfaces, minimal texture, fewer accessories, strong silhouette. The character should look [ROLE_PERSONALITY], not too friendly and not childish, with distinct facial features and a role-specific expression. Use a distinct color palette from the other roles: [ROLE_PALETTE]. The character wears [ROLE_COSTUME]. Warm atmospheric [MAP_BACKGROUND], softly blurred and simplified, not too detailed. Vertical portrait composition, centered character, same framing suitable for a role card, no text, no logo, no card frame.

Style/medium: stylized digital painting, clean simple caricature fantasy art, approachable but not childish, low texture, smooth shapes, readable costume, role clearly distinct from the other roles.

Mood: playful dark fantasy, suspicious social deduction tone, not horror and not grim realism.

Constraints: no text, no logo, no watermark, no card frame, no gore, no scary horror realism, no childlike face, no photorealism, no anime, no modern clothing, no sci-fi elements, no excessive accessories, no overly detailed texture.
```
