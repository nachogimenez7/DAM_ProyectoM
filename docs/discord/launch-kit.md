# Launch kit del Discord oficial

Este archivo contiene los textos finales para abrir el servidor **Traidores | Oficial**.

## Anuncio inicial

```text
Bienvenidos a Traidores | Oficial.

Abrimos este servidor para reunir a la comunidad desde el desarrollo del juego. La idea es que puedas conocer gente, buscar partida, seguir avances, reportar errores y proponer mejoras.

Traidores todavia esta en desarrollo, asi que algunas cosas van a cambiar. Lo importante es que este sea un lugar comodo, ordenado y seguro para jugar y hablar del juego.

Para empezar:

1. Lee las reglas.
2. Revisa seguridad.
3. Elige tus roles.
4. Presentate en #presentaciones.
5. Cuando haya gente disponible, usa #buscar-partida.

Sitio oficial: https://traidores.me
```

## Mensaje corto para redes

```text
Ya esta abierto el Discord oficial de Traidores.

Entra para seguir el desarrollo, buscar partidas y sumarte a la comunidad desde el principio.

https://discord.gg/INVITACION
```

```text
Unite al Discord oficial de Traidores.

Busca gente para jugar, segui las novedades del desarrollo, reporta errores y participa en encuestas de la comunidad.

Entrar al Discord
```

## Primer mensaje en `#presentaciones`

```text
Si sos nuevo, podes presentarte aca.

Formato sugerido:

Nombre o apodo:
Desde donde jugas, si queres decirlo:
Party game favorito:
Que te interesa de Traidores:
```

No compartas datos personales sensibles. No hace falta decir edad, ciudad exacta, escuela, telefono ni redes personales.

## Primer mensaje en `#sugerencias`

```text
Usa este canal para proponer ideas para Traidores.

Para que sea mas facil revisar:

1. Explica el problema o deseo.
2. Propone una solucion.
3. Cuenta por que mejoraria el juego.

Ejemplo:

Problema: cuesta encontrar partida rapido.
Solucion: agregar una cola simple por idioma.
Por que ayuda: reduce mensajes repetidos y junta jugadores disponibles.
```

## Primer mensaje en `#reportar-un-error`

```text
Si encontraste un error, reportalo con este formato:

Plataforma:
Version del juego:
Que estabas haciendo:
Que paso:
Que esperabas que pasara:
Captura o video, si tenes:
Se puede repetir? Si / No / No se
```

## Checklist antes de publicar la invitacion

- El servidor se llama `Traidores | Oficial`.
- El icono usa el logo real de Traidores.
- El usuario nuevo solo ve la categoria `EMPEZA AQUI`.
- Las reglas y seguridad estan publicadas.
- Los roles por botones funcionan.
- `English` queda al final y agrupado.
- `#buscar-partida` funciona como foro.
- Las busquedas se archivan a las 24 horas.
- Las salas de voz aparecen en cantidad justa: 5 en espanol y 2 en ingles.
- Los miembros no pueden mencionar `@everyone` ni `@here`.
- Hay captcha o filtro de entrada activo.
- AutoMod bloquea menciones masivas, spam e invitaciones externas.
- Tickets o canal de reportes estan listos.
- Se probo la vista como miembro normal.
- Se quito permiso `Administrator` al bot configurador o se expulso el bot.
- Se genero una invitacion permanente.
- Se agrego la invitacion a `Traidores.me`.

## Orden recomendado de apertura

1. Abrir el servidor solo a equipo y moderador.
2. Revisar permisos con vista de usuario normal.
3. Invitar 2 o 3 personas de confianza para probar entrada, roles y busqueda.
4. Corregir lo que falle.
5. Publicar la invitacion en `Traidores.me`.
6. Publicar anuncio inicial.
7. Mantener vigilancia moderada las primeras 24 horas.
