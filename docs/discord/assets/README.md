# Assets para Discord

Archivos generados desde el logo actual de Traidores:

- `traidores-discord-icon-transparent.png`: icono cuadrado 512x512 con fondo transparente.
- `traidores-discord-icon-dark.png`: icono cuadrado 512x512 con fondo oscuro y aro dorado. Recomendado para el icono del servidor.
- `traidores-discord-banner.png`: banner 960x540 para presentaciones, anuncios o redes.

## Uso recomendado

- Icono del servidor: `traidores-discord-icon-dark.png`.
- Imagen de bienvenida o anuncio inicial: `traidores-discord-banner.png`.
- Uso sobre fondos propios: `traidores-discord-icon-transparent.png`.

Estos archivos usan la paleta definida en `app/src/main/res/values/colors.xml`.
